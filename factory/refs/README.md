# factory/refs — 參考圖(不放進 git)

`factory/recipes.json` 的 `refs` 用檔名指到這個資料夾。請自己放這些圖(JPEG,長邊約 1000–1600 px 即可):

| 檔名 | 用途 |
|---|---|
| `pixar_tabby_a.jpg`、`pixar_black_a.jpg` | 「動畫風」的風格/構圖參考(手做場景的原圖) |
| `real_tabby_a.jpg`、`real_black_a.jpg` | 「寫實風」的風格/構圖參考 |
| `mycat_1.jpg`、`mycat_2.jpg` | 你家貓的照片(花色、眼睛顏色會照這兩張) |
| `heroine_morning.jpg` | 女孩場景的人物參考(原創角色) |

換成別的檔名時一起改 `recipes.json`。這些圖可能含個人照片,`.gitignore` 已排除。
